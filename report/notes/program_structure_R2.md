# Program structure after R2 (as written in 17_validation.tex; match this)

1. Phase 0 (before any grant; owner + 1 non-owner blind coder; no participants; ~EUR 10^3): V1 closure study on all 107 admissible firings x 2 arms (own, swapped) = 214 units (>= 100 double-coded), + ~100 units from one new non-gold domain; retrieval-recall arm (~50 firings searched in full snapshots); judge panel (local 7B, stronger open-weight, frontier from other families).
2. MS1 (closure verdict): CONTINUE iff human-human kappa >= 0.70 (closed vs not closed) AND retrieval recall >= floor (proposed 0.80) AND >= 1 judge beats the fair control (own-minus-control not-closed difference, 95% lower bound > 0, within +-0.10 of humans'; adopted judge also meets the adoption rule). Else STOP automated absence check -> pivots (audit tool; interview-only).
3. Phase 1 (lean methods grant, EUR 0.3-0.5M, 12-15 months), released only on MS1 CONTINUE: V0 (admissibility, dated-corpus mode, area score, deferred N2 runs), then MS2 freeze (~month 4; judge from MS1, lexicons, thresholds, area score, eligible gold list), then gold. MS1 precedes MS2 (numbering kept).
4. Judge re-validated on the later text type: closure sample from each dated V2 reconstruction (and later each V5 domain) double-coded before gold unseal; failure -> human-coded closure there.
5. V2 POOLED over >= 3 (target 4-6) published CTA golds: Sullivan 2014 (only confirmed itemized), Crandall & Getchell-Reiter 1993, Chao & Salvendy 1994, Hall et al. 1995 (PARI), further studies in Clark et al. 2008 / Tofel-Grehl & Feldon 2013; selection rule fixed at MS2. Dated corpora: Wayback CDX / Common Crawl captures before cutoff + OpenAlex-dated publications; per-gold blocklist; metadata-level size pilot; memorization probes on every model. V4 on V2 data (non-gating).
6. MS3 = SCREENING gate for Phase 2 money (not an H2 verdict): CONTINUE only if pooled dAUROC point >= delta AND lower 90% > -delta/2 AND conditional AUROC within density tertiles >= 0.5 + delta. Else STOP H2 funding (interview-only pivot costed separately). No inconclusive route. At 40/class (+-0.10) CONTINUE needs point >= 0.075; P(release | true 0) ~ 0.11.
7. Phase 2, released only on MS3 CONTINUE. V5 decides H2: ~300 areas (150/class, delta = 0.05) in 2 held-out domains, 3 experts/area, ~8-min probes, 20 areas/expert -> 45 experts + 6 pilot; ~150-250 expert-hours; ~1,200-1,900 coder hours; ~EUR 40-160k honoraria+recruitment+coding before staff time; ceiling 450 areas.
8. MS4 (V5 pilot, 6 experts x 20 areas = 40 areas): release main study only if projected areas <= 450, segmentation alpha >= 0.80, stratum guessing near chance; else stop before main study (no underpowered run).
9. MS5 (H2 verdict): STOP if upper 90% < delta; CONTINUE if lower 90% > 0 and point >= delta; otherwise inconclusive = not supporting H2, terminal for H2 funding.
10. V6 (H3, MS6), only on MS5 CONTINUE: CONTINUE if lower 90% of items/expert-hour ratio > 1 and point >= 1.25; STOP if upper < 1.25; any other reading counts against H3. Interview-only pivot is NOT H3.
11. V7 organizational pilot (MS7), only on MS5 CONTINUE + deferred N2 validation; 1 partner, 6-12 staff; descriptive.
12. V8: (a) public learner data, no gate, Phase 2; (b) Track A untouched, E-SEAL only; (c) 30-60 novices, MS8, only on MS5 CONTINUE; (d) instruction later.
13. V3 = H-OSS, organizational track (not on the H2 chain): Git adapter + code lenses (none exist), own freeze MS2b after the adapter exists, 5-departure pilot, MS5-style rule on H-OSS only; can neither stop nor license H2. Baselines include knowledge at risk (Rigby 2016).
14. External gate reader (independent statistician / board) reads MS1, MS3, MS5 with authority; owner exceptions need sign-off; none named yet.
15. V5a (expert raters of candidates) is dropped; the old "second inconclusive" rule and "pre-registered minimum" route into V5 no longer exist.
